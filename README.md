# Yarnki
Yarnki is a script that uses the website [YARN](https://yarn.co/) to download video files and make anki´s flashcards. 
Its use is educational purposes only. The main objective is learn english listening using differents kind of sounds.



## Usage

```powershell
run Yarnki.py
```
1. Install Anki Connect plugin into Anki, if you haven´t.
2. Open anki while you are using the script.
3. Make sure that exists Yarnki deck in your anki´s main view, if you haven´t you can download [here](asd).
4. If the script does not found your media folder, please enter anki´s media folder path.
5. Write an word that you want to have a flashcard, if you want some words you can separate with symbol |.
6. Enter the number of flashcards that you want, the maximum number is 20.
